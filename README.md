# 🎨 Skill-Sphere

**Skill-Sphere** is an interactive **3D virtual learning platform** designed to make education engaging and immersive for school-going students. It provides an accessible web-based space where students can explore lessons in a dynamic and visually stimulating environment.

---

## 🚀 Getting Started

This project was bootstrapped using **Create React App**.

---

## 📦 Available Scripts

In the project directory, you can run the following commands:

- `npm start`  
  👉 Runs the app in development mode.  
  Open [http://localhost:3000](http://localhost:3000) to view it in your browser.  
  The page reloads automatically when you make changes.

- `npm test`  
  👉 Launches the test runner in interactive watch mode.  
  See the **Testing** section in Create React App documentation for more details.

- `npm run build`  
  👉 Builds the app for production into the `build` folder.  
  It optimizes the React build for the best performance — the output is minified, and filenames include content hashes.

- `npm run eject`  
  ⚠️ **Note:** This is a one-way operation. Once you eject, you cannot go back!  
  It copies all configuration files and dependencies like Webpack, Babel, ESLint, etc., directly into your project, giving you full control.
